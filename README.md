# Marcador de Mus

App web para llevar las cuentas del mus desde el móvil: tantos (a 30 o a 40), juegos, vacas, órdago y deshacer.

## Instalar en el móvil
- **iPhone:** abre el enlace en Safari → botón Compartir → «Añadir a pantalla de inicio».
- **Android:** abre el enlace en Chrome → menú ⋮ → «Añadir a pantalla de inicio» / «Instalar aplicación».

Las partidas se guardan solo en cada móvil. Funciona sin conexión una vez abierta.

## Publicar una versión nueva
Al cambiar la app, sube el número de `VERSION` en `sw.js` para que los móviles descarguen la versión nueva.
